# LiveTV Pro - M3U Player

A clean, modern M3U/HLS live TV player. Auto-fetches channels from the source.

## Features

- Auto-fetches channels every 10 minutes
- HLS.js player for streaming
- Category filtering
- Search channels
- Picture-in-Picture support
- Fullscreen mode
- Responsive design
- Telegram channel link

## Deploy to Vercel

1. Push this folder to a GitHub repo
2. Go to [vercel.com](https://vercel.com)
3. Import the GitHub repo
4. Deploy

## Local Development

```bash
python -m http.server 3000
```

Open http://localhost:3000
